# 规划器接入说明

## 本插件修改的是哪一层

插件不替换 MaiBot 的调度器或规划模型。它通过宿主公开的 Hook 返回修改后的请求参数，把经过身份核验的关系信息放进规划器 / 回复器上下文。

| 阶段 | 注入内容 | 作用与限制 |
|---|---|---|
| `maisaka.planner.before_request` | 最近真实消息对应的作者、消息 ID、公开或本人关系投影、对应额外设定与分工说明 | 让规划器选择对象、行动和工具时知道关系；不是工具权限硬拦截 |
| `maisaka.replyer.before_request` | 当前回复对象的关系等级与额外设定 | 用实际回复消息确认对象，避免套用其他人的关系 |
| 回复后评分入口 | 对真实回复对象进行保守评价 | 启用自动模式后才调用模型；不允许评价器授予 3 / 4 / 5 级 |

规划器近期映射有数量上限。超出窗口、身份不匹配或找不到原消息时，不应猜测关系。引用作者、当前发送者和被提及者必须分别处理。

## 希望保持的分工

- 规划器：是否回复、回复谁、当前话题和工具行动。
- 基础人格：角色身份和整体表达。
- 好感度额外设定：面对当前对象的距离、称呼、语气和偏好。
- 回复器：组织实际语言，结合当下语境决定如何接话。

“回复参考”应提供简短话题或已核实事实，不应变成回复器必须照抄的台词。不能用规划器的临时指令覆盖基础人格与关系设定。

## 可选宿主系统提示

若宿主仍把规划器的回复参考作为高优先级台词，可以在宿主支持的自定义提示管理中加入以下原则。请按宿主版本确认模板名称；本插件不会自动修改主程序文件。

```text
规划器负责决定是否回复、真实回复对象、话题、已核实事实和工具行动；回复器负责具体表达。
回复参考只提供简短话题和事实线索，不代写台词或强制固定笑点、反问、补刀、先硬后软。
基础人格与当前可信关系额外设定共同约束表达；规划器的临时方向不能覆盖它们。
消息作者按真实账号与本机标记区分，同名、引用和昵称不代表同一身份。
```

回复器提示可相应说明：

```text
规划器的回复参考不是必须照演的脚本。结合当前原话、基础人格和可信关系设定，自行决定措辞。
与人格或关系设定冲突的表演方向可以舍弃，保留能核实的话题事实。
```

## 公开版与作者本机的区别

作者本机曾调整过宿主提示、同名账号标记与群聊寻址逻辑，并使用独立图片工具。那些主程序和其他插件改动不包含在本仓库，也不是本插件独立具备的能力。

本仓库没有附带角色人设卡、私人聊天记录或图片素材。按关系选择图片只是一种可能的工具应用，图片检索、真实发送和去重需对应工具支持。
